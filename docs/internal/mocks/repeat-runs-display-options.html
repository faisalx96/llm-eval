Outcome — what got built

A's dots + an attached drawer (no peek). The dots ship on every ×k row, fed by a new pass_summaries field in the runs-list payload. The expansion drawer is the accessible inspector panel: repeat summary, the five group metrics as percent stats, and a proper pass table on the shared table component. The verdict hover card and side peek were dropped.

Original recommendation (for the record)

A + B together. Dots give the stability story while scanning; the peek gives full pass detail without bending the table's grid. Option C was the strongest pure-table alternative — reusing the group pattern users already know — but spends k rows repeating near-identical tags.
