# Inspecting Runs

Use the CLI when you need precise run data or automation-friendly inspection, not when you want exploratory UI review. The CLI is especially useful before or after platform analysis.

## Recommended sequence

1. `qym run list --json` to discover the relevant run IDs.
2. `qym run get <run_id> --json` to fetch the resolved run payload.
3. `qym run failed <run_id> --json` to triage the problem surface quickly.
4. `qym run compare <left> <right> --json` for regression work.
5. `qym analyze run <run_id> --json` if the failure pattern is not obvious.

## When the CLI beats the UI

- CI or agent workflows.
- Bulk comparison or scripted review.
- Offline artifact ingestion followed by remote inspection.
