# qym Developer Portal

qym is an evaluation operating system for LLM products. This portal is the canonical path for developers who need to run evaluations and for operators who need to deploy, secure, and maintain the platform.

:::tip First Success
The shortest path is: install qym, configure connectivity, run one small evaluation, then inspect the result in the platform.
:::

## What qym covers

- Run repeatable evaluations from Python or the CLI.
- Score outputs with deterministic metrics, custom metrics, or LLM judges.
- Stream runs into the platform for shared review, comparison, and analysis.
- Operate the platform in connected or air-gapped production environments.
