# Install qym

Install qym from PyPI in the Python environment that will run your evaluations.

```bash
pip install qym
```

That is the normal install path for application code, notebooks, workers, services, CI jobs, and internal tools.

## Verify the SDK

```bash
python - <<'PY'
from qym import Evaluator
from qym.core.dataset import CsvDataset

print(Evaluator)
print(CsvDataset)
PY
```

## Python runtime expectations

- Python 3.9 or newer.
- A virtualenv, uv environment, Poetry environment, Conda environment, or container is fine.
- Install qym into the same environment that runs your application or notebook kernel.
- Keep one Python environment per project so SDK imports, provider clients, and notebook kernels do not drift.

## Optional platform package

Most SDK developers do not need the platform server package. Install it only in the environment that actually runs the qym platform service.

```bash
pip install qym-platform
```

If you only launch evaluations from Python and stream results to an already deployed platform, install `qym` only.

## Environment by developer use case

### Local CSV evaluation

No qym environment variables are required.

```python
from qym import Evaluator
from qym.core.dataset import CsvDataset
```

### Platform streaming

Use platform credentials when SDK runs should appear in the shared qym app while they execute.

```bash
export QYM_PLATFORM_URL=https://qym.example.com
export QYM_API_KEY=<platform-api-key>
```

### Langfuse datasets

Use Langfuse credentials only when `dataset="name"` refers to a Langfuse dataset.

```bash
export LANGFUSE_PUBLIC_KEY=...
export LANGFUSE_SECRET_KEY=...
export LANGFUSE_HOST=https://cloud.langfuse.com
```

### Judge metrics

Use judge configuration only when metrics call an LLM judge.

```bash
export QYM_JUDGE_MODEL=gpt-4o-mini
export QYM_JUDGE_API_KEY=<provider-key>
export QYM_JUDGE_BASE_URL=https://api.openai.com/v1
```

`QYM_JUDGE_API_KEY` falls back to `OPENAI_API_KEY`. `QYM_JUDGE_BASE_URL` falls back to `OPENAI_BASE_URL`.

### Phoenix tracing

Use Phoenix settings only when exporting traces to Phoenix.

```bash
export PHOENIX_ENDPOINT=http://localhost:6006/v1/traces
```

Enable it in SDK config with `phoenix_enabled=True` or the equivalent config dictionary.

## Common install checks

| Symptom | Check |
|---------|-------|
| `ModuleNotFoundError: qym` | Confirm the environment running Python is the one where qym was installed. |
| Notebook cannot import qym | Install qym into the kernel environment, not only your shell environment. |
| Platform runs do not appear | Check `QYM_PLATFORM_URL`, `QYM_API_KEY`, and platform access. |
| Langfuse dataset fails to load | Check Langfuse keys, host, and dataset name. |
| Judge metric fails before scoring | Check `QYM_JUDGE_MODEL` and judge API key. |

:::info Contributor Installs Are Separate
Editable installs from the qym monorepo are for contributors changing qym itself. Use [Contribute To qym](/contributors) for that workflow.
:::
