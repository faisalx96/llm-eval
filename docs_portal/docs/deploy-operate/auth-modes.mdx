# Auth Modes

Choose the auth model based on your network boundary and identity infrastructure, not on what is easiest for a one-off demo.

## Practical guidance

- `none`: internal or local development only
- `proxy_headers`: when an upstream identity-aware proxy injects user identity
- native login or provider-based flows: when the platform owns browser auth directly

## What changes with auth mode

- Which secrets are required
- How browser sessions are established
- Whether SDK and CLI clients need API keys for protected actions
