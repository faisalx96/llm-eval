# Production Deployment

Production means the platform is a real service boundary, not just a developer convenience.

## Production expectations

- Postgres is provisioned and reachable.
- `QYM_DATABASE_URL` is set correctly.
- `QYM_BASE_URL` and `QYM_ROOT_PATH` match the public route.
- `QYM_LLM_CONFIG_ENCRYPTION_KEY` is stable and managed securely.
- The chosen auth mode has all required secrets present.

## Validate URL correctness

If the platform is exposed under a prefix like `/qym`, the docs, API explorer, and app routes must all resolve under that prefix.
