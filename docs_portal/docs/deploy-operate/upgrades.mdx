# Upgrades And Rebuilds

Treat docs as a build artifact of the image, not as mutable runtime state.

## Upgrade procedure

1. Pull the new repo revision into the build environment.
2. Regenerate docs from repo truth.
3. Build the Docusaurus output.
4. Build the final platform image.
5. Redeploy the image and smoke-test `/docs`, `/api-docs`, and `/openapi.json`.

## Why this matters

If the image is rebuilt without the docs pipeline or with drifted node dependencies, the runtime docs surface becomes unreliable.
