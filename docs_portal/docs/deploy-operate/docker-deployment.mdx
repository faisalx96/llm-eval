# Docker Deployment

Docker is the default deployment path because it packages the platform runtime, migrations, and the final static docs site together.

```bash
docker compose -f docker/docker-compose.yml up --build
```

## What the image should contain

- Platform Python package
- Static dashboard assets
- Built Docusaurus docs output
- No runtime dependency on internet access for docs

## Validate after deploy

1. `GET /healthz`
2. `GET /docs`
3. `GET /openapi.json`
4. `GET /api-docs`
