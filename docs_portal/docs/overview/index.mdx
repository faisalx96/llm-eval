# Overview

qym has three audience paths:

| Audience | What they do | Start here |
|----------|--------------|------------|
| App Users | Use the deployed qym web app to review, compare, and approve runs. | [App Users](/app-users) |
| Developers | Build evaluations and integrations with the PyPI SDK, API, CLI, observers, wrappers, datasets, metrics, and platform streaming. | [Developers](/getting-started) |
| Operators & Contributors | Deploy the platform or modify qym itself. | [Operators & Contributors](/deploy-operate) |

The shared product loop is:

```text
developer creates evaluation -> platform stores evidence -> app user reviews result -> operator keeps runtime healthy
```

## Boundaries

- App User docs must stay UI-only.
- Developer docs assume external package consumption and begin from `pip install qym`.
- Contributor docs are the only place for repo-local editable installs, monorepo paths, docs builds, tests, migrations, and packaging internals.

## For implementation work

If you are building with qym, the main path is:

1. [Install qym](/getting-started/install)
2. [Run your first evaluation](/getting-started/first-evaluation)
3. [Read the Python API](/sdk/python-api)
4. [Configure the SDK](/sdk/configuration)
5. [Add progress, observers, and wrappers](/sdk/progress-observers-wrappers)
