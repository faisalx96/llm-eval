# App Users

This section is for people using a deployed qym web application. It explains how to find, review, compare, and approve evaluation results in the app.

App user docs intentionally avoid technical setup and repository development notes. If you are building evaluations or integrations, use the [Developers](/getting-started) section instead.

## What app users can do

- Browse runs by project, task, model, status, date, and owner.
- Open a run and inspect aggregate metrics, item-level outputs, expected values, errors, and trace links.
- Compare runs to understand regressions, improvements, and dataset changes.
- Use review state to submit, approve, reject, or annotate evidence.
- Share platform links with teammates who have the right access.

## When to switch sections

Use [Developers](/getting-started) if you need to create evaluations, write metrics, build wrappers, or automate runs.
