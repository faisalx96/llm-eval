# Minimal Task

Use this when you need the smallest code path that still represents a real qym evaluation.

## Source

- `examples/example.py`

## Exact command

```bash
qym run create --task-file examples/example.py --task-function my_task --dataset my-set --metrics exact_match
```

## What it demonstrates

- Task function execution.
- Built-in and custom metrics.
- The baseline loop before introducing deployment or operator complexity.
