# Platform Upload Workflow

Use this when the run happens offline or on a separate machine and review happens later in the shared platform.

## Recommended sequence

1. Run the evaluation locally and collect the artifact from `qym_results/`.
2. Move the artifact into a network location that can reach the platform.
3. Ingest it with `qym submit --file ...`.
4. Open the run in the platform and verify the item counts and metrics.
