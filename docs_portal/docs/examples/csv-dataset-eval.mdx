# CSV Dataset Evaluation

Use this when a remote dataset is unnecessary, unavailable, or impossible because the environment is offline.

## Exact command

```bash
qym run create --task-file examples/csv_dataset_eval.py --task-function my_task --dataset-csv ./qa.csv --metrics exact_match,fuzzy_match
```

## Expected result

- A local run artifact under `qym_results/`.
- A workflow that still works without remote dataset dependencies.
- A clean path to later upload with `qym submit`.
