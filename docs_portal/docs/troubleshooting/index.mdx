# Troubleshooting

Start with the issue that most closely matches the observed symptom. These pages focus on the failures that block real adoption: connectivity, judge metrics, and offline packaging.

## Recommended approach

1. Confirm whether the failure is local-only, platform-only, or deployment-wide.
2. Reproduce it with the smallest command or endpoint possible.
3. Only then escalate into analysis, broader refactors, or deployment changes.
